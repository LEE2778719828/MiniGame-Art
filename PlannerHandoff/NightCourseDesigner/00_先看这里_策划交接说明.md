# 夜跑程序化关卡设计器：策划交接包

## 这是什么

这是给策划调试和提交夜跑关卡参数的独立小工具：

- 双击 `NightCourseDesigner.html` 即可打开，不需要安装程序。
- 左侧修改关卡参数，右侧实时显示俯视轨迹。
- 可查看岔口位置、桥段弯折、Jump/Attack 密度和难度粗估。
- 参数可导出为 JSON，交给程序导入 UE。

## 推荐使用流程

1. 双击打开 `NightCourseDesigner.html`。
2. 先选择岔路环境和预览分支 A/B/C。
3. 调整节点数、岔路区间、旋转角、怪密度和换键频率。
4. 检查右侧俯视图和左侧统计信息。
5. 点击 `导出 Params JSON`，把文本复制保存为参数文件。
6. 如果需要让 UE 与当前预览完全一致，点击 `导出 Baked Course JSON`。
7. 将 JSON、Seed 和一张预览截图一起发给程序或主策。

## 参数口径

| 参数 | 策划含义 | 当前版本说明 |
|---|---|---|
| `totalNodes` | 基础段规模 | 当前控制基础段和岔口抽取范围；A/B/C 分支长度另由 `branchANodes`、`branchBNodes`、`branchCNodes` 控制 |
| `maxYawDeltaDeg` | 桥段最大单步旋转角 | 每步最大绝对 Yaw 变化，支持 0.1° |
| `forkNodeMin` / `forkNodeMax` | 岔口生成区间 | 在闭区间内随机抽取一个岔口石索引 |
| `forkEnv` | 岔路环境类型 | `ClearAB`=AB、`FogAC`=AC、`ReverseBC`=BC、`Custom`=自定义 |
| `seed` | 随机种子 | 固定数字可复现；填 0 或留空则随机 |
| `keySwapEveryNNodes` | 换键周期 | 分支每经过 N 个节点安排换键 |
| `keySwapCountPerPeriod` | 每周期换键次数 | 0 表示关闭换键 |
| `attackBias` | 怪/砍密度 | 0–1，数值越大 Attack 越多，是概率而不是绝对比例 |
| `maxSameActionStreak` | 连续同类动作上限 | 防止连续过多 Jump 或 Attack |
| `jumpGapCm` | 跳跃间距 | 数值越大，跳跃体感越难 |
| `killGapCm` | 砍怪间距 | 数值越大，目标石距离越远 |
| `branchANodes/BNodes/CNodes` | 各分支长度 | 只影响对应分支 |

## 两种导出

### Params JSON

日常推荐使用。只保存参数，UE 根据 Seed 重新生成轨道。

适合：

- 策划提交关卡参数；
- 程序继续调整生成规则；
- 需要同 Seed 批量复现的关卡。

### Baked Course JSON

除了参数，还保存每块石头、每段桥和每个动作的结果。

适合：

- 评审当前俯视图；
- 验证 HTML 与 UE 的轨迹一致；
- 需要锁定某一次具体布局。

## 文件命名建议

```text
L2_AC_seed1001_v01_params.json
L2_AC_seed1001_v01_baked.json
L2_AC_seed1001_v01_preview.png
```

固定 Seed 后，参数文件和预览图应保持同名同版本。

## 发给程序时请附带

- 关卡 ID：例如 `T0`、`L1`、`L2`、`L3`；
- 使用的环境/路线：AB、AC 或 BC；
- JSON 文件；
- Seed；
- 预览截图；
- 需要重点检查的节点区间；
- 对密度、难度、岔路位置的备注。

## UE 导入方式

策划通常只需要提交 JSON。程序在 PIE 控制台执行：

```text
Night.Course.ImportParams Saved/NightProcCourseParams.json
```

如果要验证 HTML 烘焙结果，使用 Baked JSON；如果只想让 UE 根据参数重新生成，使用 Params JSON。

## 当前版本边界

- `forkEnv` 当前主要用于路线组合映射，实际环境美术仍由 UE 资产配置控制。
- HTML 的难度值是相对粗估，用于比较不同方案，不作为最终数值。
- 轨道仍遵守“落脚石链”：空档对应 Jump，目标石带怪对应 Attack。
- 错键不会推进角色，必须按当前窗口要求的动作。
